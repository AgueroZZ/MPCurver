# MPCurver 0.4.1 publication

At the user's request, promote the local 0.4.0.9000 development checkout to
0.4.1 and prepare its code, tests, documentation, and generated site for
publication on main and the v0.4.1 tag.

Isomap now selects the smallest connected union-kNN neighborhood by default,
independently within each feature group. Explicit counts remain fixed.
Neighbor queries exclude the sample itself and break distance ties by row
index; ordering results and initialization metadata record `k_used`.
The changelog, README, reference pages, and fitness vignette describe this
behavior. Fitness figure titles have been shortened to avoid clipping.
The site builder now removes trailing whitespace from generated HTML.

Historical experiment versions and frozen archives in InferOrder retain their
actual fitting provenance. This release publishes the existing connectivity
default; early-ELBO screening remains experiment code.
