# MPCurver 0.4.2 release

Release commit `db232d9e039eab0c86092db496af94f47b255b71`, tagged `v0.4.2`
(annotated tag `d8110d8b77a228d4d34e56fa250570f163902ade`) and fast-forwarded
from `4f8b583d7549d4068d0e810e93f90653cbcb2ed9` (v0.4.1).

MPCurver now fits data with missing entries. Partial `NA` observations are
accepted by single- and multi-ordering CAVI, known measurement-noise fits,
continuation, and dimension selection. Missing entries are integrated out
under an ignorable missingness assumption. Position, trajectory, variance, and
objective calculations use the observed entries, as masked matrix products.
Feature similarities are pairwise-complete, and feature-mean filling is
confined to ordering initialization. Complete-data results equal 0.4.1. The
exceptions are intrinsic trajectory updates made singular by positions
collapsing onto too few bins, which now stop with an error, and random starts,
which now cut a random permutation into position bins. Messages report
one-feature similarity clusters and, for missing data with an adaptive position
prior, suggest a fixed position prior. Unused SmoothEM/csmoothEM code,
unreachable CAVI-era code, earlier-version compatibility code, and constant
result fields were removed. Exported function signatures are unchanged.

The mathematics is in `important_derivations/missing_data_cavi_derivation.Rmd`.
The validation study and its record are in `experiments/missing_data_v042/`.

## Release verification

- Full source tests pass 1,885 expectations, with zero failures, errors,
  warnings, or skips.
- `experiments/missing_data_v042/verify.R`: 24 complete-data configurations
  are identical to 0.4.1. All 72 missing-pattern fits agree with an
  independent scalar objective (maximum discrepancy `1.023e-12`) and
  increase monotonically.
- Independent checks: a missing entry matches an infinitely noisy observation
  on the complete-data path (positions within `9e-16`). A per-entry
  re-implementation of single-ordering CAVI matches to machine precision.
- InferOrder studies refit under 0.4.1 and 0.4.2 with identical results: the
  single-ordering comparison (28 sampled inputs), forward selection and
  adaptive M = 8 for the estimate-M studies, the site simulations, pancreas,
  and the five fitness-vignette fits.
- `R CMD check --no-manual` returns **Status: OK** with zero errors,
  warnings, or notes; all six vignettes execute and rebuild. The checked
  source archive has SHA256
  `73953899fb4096cab546d08356aad782c2e0e82fbc5b910d155b82d7b07398e0`.
- The pkgdown site was rebuilt with `scripts/build_public_site.R`. Its 38 HTML
  pages pass the local-resource and caption audits, and all 33 PNG figures
  are unchanged.
- Publication changes pass credential and local-path inspections. Agent
  planning notes stay local under the ignored `plan/`.
